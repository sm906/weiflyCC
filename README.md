# WeiflyCC Ecosystem

WeiflyCC 是一套持續演化的數位生態系（Digital Ecosystem）。

WeiflyCC 並非單純網站、Dashboard、Home Lab 或雲端平台，而是透過 Core、Realm、Gateway 與 Resident 連結多個外部生態系，長期發展目標為 WeiflyOS。

---

# Core Philosophy

One Core

Multiple Realms

Connected Ecosystems

---

## Core Principles

- 永遠只有一個 Core
- 永遠只有一個 WeiflyCC
- Realm 可以成長
- Ecosystem 可以擴張
- 技術可以替換
- 架構優先於技術
- 生態持續演化

# CC Family

CC Family 為 WeiflyCC 生態居民（Residents）。

不是客服。

不是聊天機器人。

不是固定 Widget。

而是居住於 WeiflyCC 生態系中的導航員、助手與智慧代理。
